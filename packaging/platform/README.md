# whatsapp-axi-${os}-${cpu}

The `whatsapp-axid` daemon of [whatsapp-axi](https://github.com/JarvusInnovations/whatsapp-axi),
prebuilt for ${os} on ${cpu}. Install `whatsapp-axi` instead: it lists this package as an
optional dependency, and your package manager installs it only on a matching machine.

The binary includes a GPL-3.0 library, so this package is distributed under GPL-3.0-only
([LICENSE](LICENSE)). [NOTICES](NOTICES) lists every component compiled in, with its version and
licence, and [SOURCE.md](SOURCE.md) says where the complete corresponding source is and how to
build the binary from it. The `whatsapp-axi` CLI is a separate program, under MIT.
